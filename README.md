## 🎓 Training

This project was developed as part of my training at the **Information Technology Institute (ITI)**.

The project demonstrates practical experience in building a Business Intelligence solution using SQL Server, Power BI, Power Query, DAX, and dimensional data modeling.

## 🗄️ Data Source

The project uses data from **AdventureWorks2022** through SQL Server.

The data model includes:

- Fact Order Details
- Products
- Sales Persons
- Ship Methods
- Order Statuses
- Territories
- Date Dimension
